# Threat model

Maps the [OWASP Top 10 for Agentic Applications 2026](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/)
(ASI01 to ASI10) to what this lab does about each risk, the test that
proves it, and the open issue where a gap remains. `tests/test_threats.py`
fails if a row loses its control, or cites a test file or test that does
not exist, or has neither a test nor an issue.

Scope: one operator, one machine, no internet-facing service. The
adversary is content the agent reads (a web page, an issue, a document,
a tool result), a mis-wired handler, and a compromised dependency. Not in
scope: a hostile operator, a hostile OS, multi-tenant separation
(deferred by ADR 0005, #41).

Status words are literal: **enforced** means code refuses it and a test
shows so; **partial** means enforced for what exists today with a named
gap; **gap** means not yet built.

## MCP servers (#256)

An MCP server touches four rows above. Its tool descriptions and its output
are text an outsider wrote (ASI01). It can be updated to change what a tool
does after the operator looked at it, the rug pull (ASI04). It is a program
that runs on the machine (ASI05). And a tool call is an action (ASI02).

What `lab/mcp.py` and the broker do about it:

- The operator signs each server entry: the exact argument list, the allowed
  tools and a SHA-256 of each tool's name, description and input schema. An
  unsigned or edited entry cannot be called.
- Every call compares the live tool with its signed fingerprint. A changed
  tool is refused until the operator signs again. A new tool is not allowed.
- `mcp.call` is approve tier and the approval is bound to the signed entry.
  It counts as untrusted input for the Rule of Two, so it cannot sit beside a
  credentialed connector.
- Output and descriptions come back as fixed-schema evidence. A JSON-RPC
  error passes on its code, never the server's words.
- The server runs with no shell, a minimal environment, under Seatbelt, and
  with no network unless the signed entry and the task's egress list allow
  it. Message size, calls per task and time are capped, and the process
  group is killed at the deadline, on a stop and after every call.

Since 2026-10-01, by the owner's decision, one reviewed handler holds
`mcp.call`. It is granted only the servers in the signed file and no
network, and a file with any entry that does not verify stops the daemon.

Proof: `tests/test_mcp.py`, against a fake server on real pipes, and
`tests/test_grant_skill_mcp.py` for the handler. Open: the Seatbelt run of a
real server on the Mac is a step in `ops/mac-session.sh`.
A server allowed the network has all of it, since Seatbelt cannot filter by
host name.

## What this document does not claim

- Coverage of risks outside the OWASP list, such as model theft or
  training-data leakage. The lab trains nothing.
- That partial rows are safe to run against real credentials. SECURITY.md
  lists what must exist before that: egress control (#14), a secret
  broker (#15), and a separate operator account (#70).
- That the tests are exhaustive. They prove the named behaviour, not the
  absence of other flaws.
