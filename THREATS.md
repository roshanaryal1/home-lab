# Threat model

Maps the [OWASP Top 10 for Agentic Applications 2026](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/)
(ASI01 to ASI10) to what this lab does about each risk, the test that
proves it, and the open issue where a gap remains. `tests/test_threats.py`
fails if a row loses its control, or cites a test file or test that does
not exist, or has neither a test nor an issue.

Scope: one operator, one machine, no internet-facing service. The
adversary is content the agent reads (a web page, an issue, a document,
a tool result), a mis-wired handler, and a compromised dependency. Not in
scope: a hostile operator, a hostile OS, multi-tenant separation
(deferred by ADR 0005, #41).

Status words are literal: **enforced** means code refuses it and a test
shows so; **partial** means enforced for what exists today with a named
gap; **gap** means not yet built.

## What this document does not claim

- Coverage of risks outside the OWASP list, such as model theft or
  training-data leakage. The lab trains nothing.
- That partial rows are safe to run against real credentials. SECURITY.md
  lists what must exist before that: egress control (#14), a secret
  broker (#15), and a separate operator account (#70).
- That the tests are exhaustive. They prove the named behaviour, not the
  absence of other flaws.
